# 视觉系统

读取真实画布尺寸，统一标题、内容与页脚区域以及边距。将参考比例映射为原生坐标，检查元素不越界和非预期重叠。选一个可用中文字体，保持标题、正文和关键数字的明显层级；配色围绕背景、主强调和辅助色展开，辅助元素降低视觉权重。

每页突出一个主要视觉：指标、真实可编辑图表、对比或有意义的流程；让它占据足够面积。根据内容变化采用非对称、图文对照或跨栏布局，避免每页相同小卡片，也不按固定比例硬凑版式。留白服务于阅读，密集材料可用清晰分组和适当分页。

图表沿用原生 chartData，系列颜色一致、标签与单位可读；不要画假图表或制造数据。图片使用用户提供或实际获得的素材，不构造字节。保存后检查标题、对齐、颜色、图表及事实；没有真实预览就说明视觉未验证。字体与组件效果受当前原生 schema 支持范围约束。
