# 编辑、资源检查与成果交付

修改前读取当前内容、来源和修订；只改用户要求的行为，保留有效专业规则和定制素材。冲突先刷新再合并，不覆盖未知改动。名称冲突不等于用户授权替换现有技能；使用真实管理服务，不能绕过 Host 写官方目录。

当前自然语言草稿工具只承载 SKILL.md，并仅支持 shared-agents/profile。完整资源树不能通过保存一段文字自动发布；制作完整包时改走 bundle-production.md 中的工作区脚本、ZIP 和专用导入流程。计划中的文件不能当成已存在的引用；缺少必要资源时说明缺口，不能宣称技能已完整可用。完整 bundle 的浏览器导入使用专用预检与确认界面。

分别核验：元数据与正文合法、引用的文件真实存在、资源满足输入/输出契约、实际任务成功、最终制品可获取。格式校验并不检查专业结论。发布回执证明安装结果，不证明试用成功或分享包存在。

试用至少包含典型请求、易混淆的不适用请求、缺输入/资源的失败情形。比较预期与实际成果，记录未达标部分；没有真实试用就明确“未执行”。不得自动发送试用任务。

交付回复说明真实保存/发布状态、适用范围、准确调用命令、已验证内容和未解决项。只有真实文件或下载回执存在时提供制品；不把文档说明写成“附件已生成”。未来更新不得静默覆盖用户定制；不伪造第三方 userModified 元数据。
