# Word 校验与真实交付

审查按内容、结构、排版、资源和制品分开，不把某个HTML评分当成DOCX质量证明。

内容：数字与来源一致，事实/建议/待确认明确，无虚构引用、工作成果或人员承诺。结构：章节关系清楚，列表保持顺序，表格标题/表头/单位明确，没有为装饰凑空段。排版：字号层级一致、对齐合理、无明显裁切，表格与图片可读。

原版HTML规则中可借鉴层级、合法结构、语义表头、图注与链接检查；CSS继承和转换器特定的封面对齐补丁不直接适用于原生Word模型。不要为通过评分给每个章节补无意义概述。

图片复用按 content_read 返回的 office-image 引用复制，只在授权工作副本间操作；不能从占位值重建二进制。图片来源不能使用时继续完成支持的正文，说明缺口，不宣称附件已插入。

编辑、保存、显示与导出分别使用真实回执。新建先打开并写首段，后续按章节提交，人工接手暂停写入，修订冲突重读。最后 content_export 交付真实DOCX卡；失败说明原因和右侧下载方式。当前子集不保证复杂文档无损往返，不能称已精确还原分页或嵌套表格。

用户要求修改时保留原文未涉及部分，不为套新体裁重写全文。完成回复说明实际提交内容、导出文件和影响交付的限制；未执行视觉/文件重开检查就不声称检查通过。
