# 工作簿结构与公式方法

先分清新建模板、从真实材料整理、编辑原文件、计算分析和公式审查。不要把原表编辑改成从零生成，也不因为没有文件就捏造真实数据。演示数据只在用户要求样例时生成并明确标记；空模板保留输入空白，真实材料按真实记录处理。

选择记录、统计、计算模型、计划、日历、打印表单或看板原型，可组合但不超出用户需求。定义工作表角色、字段类型、数据来源、单位、数据范围、输入列与计算列。必要时拆分明细与汇总，汇总引用真实明细，不维护第二份手工总数。

先确定标题、表头、数据起止行、合计行与区块，再写公式。数据第3–5行，合计第6行时不能仍用第2–4行范围。跨表引用必须读取源表实际结构，不能根据“公式看起来合理”认定正确。

计算列的公式、起始位置和填充范围保持一个权威定义，其他说明引用它；不要在多个Notes重写成不同公式。允许公式只取决于实际引擎支持，未支持函数不能假定会重算。

| 运算 | 检查 |
| --- | --- |
| 差异/余额 | 必要空值保护，合法0不得当作缺失 |
| 比率/同比/达成 | 分子缺失处理、分母缺失及0保护 |
| 合计 | 包含真实首末行、不含自身合计形成循环 |
| 跨表查找 | 源sheet、键、单位、唯一性与范围明确 |

例如目标B3、实际C3的达成率可用 =IF(OR(C3="",B3="",B3=0),"",C3/B3)，仅在工具支持该函数时采用；格式百分比不等于值乘100。业务利率、单价等可变假设放输入单元格引用，避免藏在公式硬编码。readback公式文本与实际计算值分别核验；没有计算引擎时不能声称已重算验证。
