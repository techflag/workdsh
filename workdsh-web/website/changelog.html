WORKBUDDY OPEN SOURCE ALTERNATIVE

Looking for an open-source WorkBuddy alternative?

WorkDSH follows a similar workspace model while remaining an independent community project. It imports WorkBuddy Skill packages containing SKILL.md and expert packages, then extends DeepSeek Harness with a local Library, Word, PowerPoint, Connectors and Agent Teams. The MIT-licensed source can be inspected, changed and deployed for your own team.
