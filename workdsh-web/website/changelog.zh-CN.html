WORKBUDDY OPEN SOURCE ALTERNATIVE

寻找 WorkBuddy 开源版或可扩展替代方案？

WorkDSH 借鉴 WorkBuddy 的工作体验，但由社区独立开发。它支持导入包含 SKILL.md 的 WorkBuddy 技能包和专家包，并通过 DeepSeek Harness 原生插件扩展本地资料库、Word、PowerPoint、连接器和 Agent Team。项目采用 MIT 许可证，可查看源码、修改界面并按团队需求部署。
