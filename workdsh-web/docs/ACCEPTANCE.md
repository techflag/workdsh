## A16 必须交付的固定验收链

1. 在 expert-manager 对话中创建“客户跟进专家”。
2. 在 skill-creator 对话中创建“逾期检查”技能并绑定专家。
3. 创建测试客户系统连接实例，完成专用授权界面流程。
4. 将风险规则文件导入资料库，加入专家任务。
5. 专家加载技能并读取规则，通过测试 MCP 查询客户。
6. 校验待提交记录，遵守任务已有授权后提交。
7. 读取外部记录核对，保存报告与回执到资料库。
8. 另一专家通过关联任务读取报告继续加工。
9. 重启后任务、对象修订和成果可查看。
10. 重复验证未授权、网络超时但远端成功、技能缺失、部分写入和取消场景。

每一步必须有实际服务结果或会话工具记录；截图中存在按钮、模型回复“已完成”、mock 工具无条件返回成功均不算验收证据。

## 测试层次

单元：领域校验、修订冲突、依赖解析、写入核对。
集成：契约注入、插件生命周期、原生执行接口、持久化恢复。
E2E：页面与对话两条管理入口、业务链和异常交互。
真实模型 smoke：显式选择配置，不默认产生外部费用或业务写入；记录模型和真实产物。

## 团队基础用例（阶段以 acceptance.json 为准）

- T01：两个组织使用相同显示名称对象，查询/搜索/缓存/下载/预览不得串数据。
- T02：前端或模型伪造 organizationId、principalId、sessionId，Host 拒绝越权。
- T03：普通成员无权创建组织共享连接，具备权限的成员可使用已分配连接但不能读取凭据。
- T04：共享专家为不同用户创建独立会话；分享专家不分享历史、个人资产或账号。
- T05：撤销成员/连接授权后，后续调用和订阅不继续访问；已完成外部副作用保留回执，不声称回滚。
- T06：管理员能管理组织配置，但默认不能读取用户私有对话。
- T07：管理页面和 Agent 工具对同一动作返回一致授权结论。
- T08：会话列表、会话流、文件路由、原生 Remote 与 MCP 路径全部校验，而非只过滤工作台页面。
- T09：P1，委派契约保留发起主体，未实现工作流/子 Agent 的团队入口拒绝执行；共享连接记录真实成员及代用账号。
- T10：P1，团队运行提供方未实现时关闭团队远程执行入口，不能用本地单用户执行器替代。
- T11：schema 从首期保留归属与版本；显式导入个人资源到团队，旧资源未被静默公开。
- T12：用量按组织/主体/任务归属，重放事件不重复记账；缺失指标标为未知而非零。

- T13：后台入口及 Remote 权限一致，组织 admin 不等于宿主运维；组织对象状态与用户工作台一致（P1-10）。

## 项目与核心领域补充

- J01：P1，创建空项目并重启，中心可搜索；模板预填可编辑，不自动执行。
- J02：P1，同用户两个项目采用不同指令和技能，任务快照互不污染；修改配置后旧任务仍引用旧修订。
- J03：P1，项目资产上传→授权检索→任务读取→保存成果→另一任务复用；仅一个资产正文源，关联失败可恢复而不重复上传。
- J04：P1，执行成功不能无证据完成业务待办；多次执行可关联同一待办；expectedRevision 拒绝并发覆盖。
- J05：P1，关联任务不自动共享正文；无权限者不能从动态、搜索、预览或摘要推断私有内容；撤权后订阅停止。
- J06：P1，交接摘要和选定资产创建关联任务，接收方重新绑定连接；缺权限或依赖返回诊断，外部写入不重放。
- J07：P1，个人和公共同名连接独立选择；双主体测试证明协作上下文拒绝个人连接，不回退账号。真实多人入口另见 J07-P3。
- J08：P1，技能停用不修改 SKILL.md 且新调用不可用；启用恢复；卸载显示依赖影响并保留历史引用。专家置顶不改变运行绑定。
- J09：P1，MD 建议接受前正文不变，拒绝无覆盖；基础修订变化导致冲突；容量预检与提交检查均有效。
- J10：P1，项目归档、能力缺失、关联失败、权限变化均有真实诊断。后续行为拆至 J10-P2/J10-P3。

## 单阶段追加用例

- J07-P3：真实多人会话只能使用授权公共连接，个人连接不能被其他成员调用。
- J10-P2：项目自动化及通知只对创建者可见。
- J10-P3：真实邀请审批、过期撤销与多人执行权限正确。
- T09-P2：实际工作流和子 Agent 运行不提升发起者权限。
- T10-P3：真实团队 runtime 隔离文件、进程与凭据，验证越界访问失败。
- A20-P3：团队存储提供方并发修改冲突可见，不丢更新。
- B01：暂停任务后改变同一连接账号或目标，恢复拒绝静默写入；同账号凭据轮换允许但权限撤销仍阻止操作。
- B02：跨主体测试原任务含接收人不可读的标记信息，干净摘要/交接包不含该信息；准备后撤权使领取失败。
- B03：原生文件工具、脚本、符号链接及重命名不能覆盖权威正文；不支持隔离则受管任务禁用危险工具，仍无法收口则阻塞功能。
- B04：P1 界面只支持同主体专家交接；成员间真实交接不展示可执行假入口。
- B05：浏览器关闭/多标签不改变 Host 调度次数，Host 重启恢复一次，第二个调度所有者被拒绝。
- Q01：公开包可建立无原始私有会话历史的新会话，并注入选定测试材料。
- Q02：P3 企业阶段；公开文件/脚本能力能否限制权威存储写入；记录可保护路径及必要禁用规则，不能假定目录隔离有效。
- Q03：P3 企业阶段；公开机制支持完整执行入口的主体关联与拒绝无身份访问；未保护路径不得开放团队模式。
- Q04：最小发布包卸载/重装、两测试组合与持久恢复探针有实际证据，不能以源码链接替代安装。

所有用例的阶段、任务、状态及证据统一由 acceptance.json 保存。Markdown 是场景描述；check-plan 校验映射完整，check:acceptance 用于阶段发布门槛，待验证用例导致门槛不通过是正常结果。
