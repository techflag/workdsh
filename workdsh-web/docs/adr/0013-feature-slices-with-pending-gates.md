# ADR 0013：按可用功能切片交付，保留未完成门槛

状态：接受，2026-09-10。依据用户要求减少独立验证、继续交付技能功能。

D01 的未完成项仍记录，不能标成通过；允许 D03 技能的原生目录浏览切片提前实现，只消费现有官方 Session/skills Remote。该切片不创建 WorkDSH 业务对象、不开放多人能力。D02 身份授权与 D03 导入/修订仍是业务写入的前置；自有 Remote 兼容问题只阻挡需要它的操作。开发顺序增加 activeSlice，记录已批准的跨阶段范围，不能据此任意展开所有插件。

每轮围绕用户可操作的结果实施必要验证，不把额外探针当作持续交付。首个切片：任务选择、真实技能列表、组合搜索、使用说明、返回原生任务与复制调用命令。下一切片：本地导入与不可变修订及相应业务准入。
