# ADR-0006：逐插件开发和独立版本交付

状态：采纳，2026-09-10。

背景：用户要求逐个开发可版本化插件，并担心顺序未落盘导致任意推进。

决策：保留单仓库多包；按 PLUGIN-DELIVERY 的步骤与依赖推进。独立包版本、业务对象修订、组合版本分别管理。当前先处理审查再开展安装链探针。

比较：一次实现所有插件便于同时展示，但难以定位依赖失败；每插件独立仓库增加首期契约协调成本。采用当前 monorepo 逐插件交付，保留全部占位目录。

后果：每步需要证据与台账；下游到位后仍须跨插件验收，单插件完成不代表产品发布完成。基础包需增量维护，不为独立版本重新实现 Harness 运行器。
