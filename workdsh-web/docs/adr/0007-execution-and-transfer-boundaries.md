# ADR-0007：连接绑定、资产修改与交接边界

状态：设计采纳；运行保障等待 P0 探针及各阶段测试。本 ADR 关闭 R01—R05 的设计歧义，不声称实现通过。

## 连接身份（R01）

绑定记录 connectionId、configRevision、targetFingerprint、externalPrincipalId 和授权工具范围。目标指纹由服务规范化 endpoint/服务租户/账号标识生成，不含密钥。账号、目标或工具授权范围改变使旧绑定需要显式重绑定，旧任务不得自动采用新配置。同账号同目标的短期凭据轮换允许专用凭据服务刷新，每次调用仍重查权限；无法确认外部账号身份时不得静默轮换。调用拿到与检查同一修订的不可变配置/客户端句柄，禁止检查后再读取可变默认实例。已发请求保留原目标回执。

## 交接（R02/R05）

P1 用户界面只交付同主体切换专家的新任务。跨主体 prepare/claim 服务以隔离测试身份验证；真实接收者选择、通知和邀请入口 P3 才开放。

交接包记录允许分享的资产修订/业务字段、来源、目标主体、准备时间和过期时间。摘要生成在独立干净会话中，只接收目标有权读取的源材料；不向该生成器提供发送者原始私有会话、个人工具结果或完整历史。无法确定来源的原摘要不能自动传递。准备、生成前、领取时分别重查；任何源撤权使准备包失效，不尝试通过提示词自动脱敏后继续。共享新内容须走单独显式发布授权，不能借交接扩大权限。即使同主体也只传选定材料，不复制日志，不重放外部提交。

## 正文与工作副本（R03）

library 权威正文与数据库属于 Host 私有存储；Agent 工作目录仅包含导出的只读修订或可写副本。既有资产修改必须 proposeRevision，接受方具有 edit 权限才可用 baseRevision 原子提交。首次新建资产也走资源服务，不能凭路径直接登记任意 Host 文件。

仅把文件放在另一个目录不足以防止同 OS 身份下的任意 shell 访问。P0-05 必须实测原生文件工具、脚本、符号链接、重命名等全部写路径。若官方公开沙箱不能保护权威存储，受管资产任务禁用通用 shell/文件写工具，只开放服务工具和受控工作副本接口；若工具不可完整收口则阻塞该能力，不声称审阅保障。团队任意代码执行另需隔离 runtime。

## 自动化（R04）

单 Host 调度所有者持久管理规则与触发记录，浏览器只配置/订阅；关闭标签不停止 Host 调度。Host 停机后按已约定错过策略合并恢复，稳定 occurrenceId 防重，运行前重查创建者/项目/连接授权。首期不允许多个 Host 同时拥有同一调度库；第二个所有者拒绝启动。多 Host 租约另立 ADR。交付前测试多标签、Host 重启、错过触发与不确定提交，不把定时器 tick 当作执行成功。

## 取舍

代价是更严格的执行能力边界与额外引用记录；收益是避免账号静默变化、摘要泄露与正文绕审。没有选择完整日志复制或仅提示词约束，因为它们无法提供本需求所需保证。数据迁移与完整团队部署仍按已有阶段，不额外复制 Harness 运行器。
