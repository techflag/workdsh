# 企业管理后台设计

状态：后期 ToDo，尚未实现。企业版采用独立服务端与管理 Web；当前产品不显示管理假入口。

## 1. 企业服务端与两个 Web 入口

用户工作台负责创建任务、使用专家和技能、管理个人资料和参与项目。

企业管理后台负责组织治理、成员、共享能力、连接授权、模型策略、审计与用量。由 plugin-admin 提供独立管理布局和导航，通过领域服务操作，不另建一套专家、技能或连接器数据库。

企业版采用独立 WorkDSH 服务端和独立管理 Web。用户 Web 与管理 Web 调用同一组服务端领域 API；Harness Host 或隔离 Worker 是执行节点，不承载企业数据真源。当前阶段只保留设计与模块 ToDo，不创建服务端、管理页面或伪造企业数据。

## 2. 管理模块与阶段

| 模块 | 管理内容 | 首期 | 完整阶段 |
| --- | --- | --- | --- |
| 组织概览 | 当前组织、身份、配置与能力状态 | 实现基础状态 | P3 增加运营聚合 |
| 成员与角色 | 邀请、停用、角色、项目成员 | 基础成员列表及角色检查，local 模式不假装真实邀请 | P3 SSO 与邀请 |
| 专家/技能/应用 | 组织发布、停用、修订、分配 | 实现组织对象范围与发布/停用 | P3 审核与批量分发 |
| 连接器 | 组织实例、凭据配置、使用范围、状态 | 实现基础管理和授权范围 | P3 企业接入扩展 |
| 项目与资料 | 项目角色和共享范围 | 服务权限及基础入口 | P3 团队协作与审阅 |
| 模型与策略 | 组织可用模型、访问范围 | 契约与只读能力状态，未执行策略标明未支持 | P3 策略管理 |
| 插件治理 | 已安装功能、版本、来源、兼容性 | 只读列表及安装说明 | P3 受控安装/审批；组织管理员不自动等于宿主运维 |
| 审计 | 配置变更、授权和业务动作 | 基础受限查询 | P3 检索导出与保留政策 |
| 用量 | 组织、成员、任务、模型统计 | 事件归属契约 | P3 可用数据看板 |
| 部署与安全 | SSO、运行隔离、网络与备份 | 状态提示和准入边界 | P3 部署管理 |

Skill 管理遵循 [ADR 0015](adr/0015-skill-control-plane-and-runtime-projection.md)：后期管理 Web 提供组织 Skill 列表、分类管理、下发策略和成员自定义 Skill 策略；企业服务端拥有对象与不可变修订，执行节点只同步授权投影。当前不建设公共市场，默认技能继续来自 Harness。

首期未交付的模块可作为明确标注“规划中”的后台说明出现，但没有可点击的假操作或假数据。与普通工作台不同：工作台只展示可用业务入口。

## 3. 权限与管理行为

管理布局不是授权边界；每条 Host API 都校验主体、组织与动作。成员伪造路径也不能调用管理功能。

组织 owner/admin 可管理组织设置与成员，不默认读取私有对话或个人凭据。修改成员权限、发布/停用共享对象、分配连接均记录审计。

宿主级插件安装能执行代码，属于部署运维权限，不直接授予普通组织 admin；首期安装仍使用官方 CLI，不开放浏览器任意 npm 安装。

共享服务账号只给授权成员工具使用能力，前端和 Agent 不获密钥。禁用连接后拒绝后续调用，对已完成副作用记录结果。

## 4. 首期验收 P1-10

- 有权限主体可进入管理布局；无权限主体直接调用 Remote 同样被拒绝。
- 管理页与工作台调用同一对象服务，发布或停用后实际目录状态一致。
- 用户 A 创建的私有对话不会因为用户 B 是 admin 而自动可见。
- 成员/连接授权变更有身份化审计，并影响后续调用。
- 本地模式显示个人组织与单用户能力，不展示伪造的团队成员、邀请成功或用量。
- 两组织切换/请求不会复用错误的缓存与数据。

## 6. 设置与秘密的管理边界

管理端同时展示三类状态，但数据来源不同：插件运行设置来自官方 Settings descriptor，组织策略和对象治理来自 WorkDSH Domain，连接秘密来自 Credentials 的只写/状态接口。界面可以统一视觉组件，不能用同一份通用配置 JSON 保存三类数据。

- Settings 页面仅加载脱敏 descriptor，编辑携带 expected revision；冲突提示重新载入，`applies` 只展示生效方式。
- 凭据页面只显示引用路径、来源、是否配置、是否可写和授权状态；不提供读取明文、复制令牌或把 secret 放进浏览器状态的接口。
- 组织策略修改继续经过 access、业务修订与 audit；Permission Preset 只影响任务的审批/sandbox 选择，不能编辑成员角色或资源 ACL。
- 插件卡片的“已启用”表示 Fiber/配置状态；是否在左栏显示、是否允许某组织使用、是否配置凭据、是否具备隔离保证分别展示。

Remote 仅承载一元管理操作。列表分页、审计增量、连接健康流和运行状态订阅使用独立查询/流协议；所有入口都执行同一 ActorContext 授权。治理边界见 [Harness 治理能力复用矩阵](research/harness-governance-capability-matrix.md)。
