# U2 文档常用工具栏验收

日期：2026-09-12。用户反馈现有文档页仅正文/B/I/U/S，与 Word 差距较大。

## 实现与复用

复用 Tiptap/ProseMirror 3.31.0 的原生列表、History、公开 commands，新增同版本 MIT TextStyleKit、TextAlign；无商业扩展、服务器转换或本地 Office。Office 独立插件、Client model/actions 和 Host 统一内容服务保持不变。新增字体、点字号、颜色、高亮、标题1—6、对齐、行距、缩进、列表、撤销重做、全选/清除格式、查找替换、缩放及字符数；工具栏分组换行。

格式进入语义契约和 AI 输入 schema；Host 拒绝非法颜色/字号/层级，保持批次原子性。原生列表使用真正的 listItem，不使用文字模拟序号；下载生成 OOXML numbering.xml，并保留文字/段落样式与列表起始编号。旧无可选样式的记录继续兼容。

## 边界

查找为区分大小写的段内字面匹配，不支持正则或跨段匹配；多选区样式不显示“混合”。字体来自浏览器可用字体，未新增系统字体安装。系统 IME 与 Word/WPS 真实分页检查未执行，DOCX 属性检查不代表分页保真。文档表格、图片、页眉页脚、分页和既有 DOCX 保真导入仍待开发；其他七类未借本次检查标完成。一次保存仍受 Host 100 操作的批次上限约束；超过100块的整体排版需要后续分批保存支持，本轮没有验收超长文档全选排版。全仓回归未执行，未提交/推送/发布。
