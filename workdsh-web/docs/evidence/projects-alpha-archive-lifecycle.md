# Projects Alpha 归档生命周期证据

日期：2026-09-17。对应 J10 的项目归档子项；J10 其余能力缺失、关联失败与权限变化诊断仍需单独验收，因此 J10 保持 pending。

## 已实现

- 项目卡片点击“归档”先显示确认弹框，取消不改变项目。
- 确认后项目从进行中列表移入“已归档项目”，不再允许打开或创建任务。
- 已归档筛选可以搜索和查看历史项目，并提供明确的“恢复”操作。
- 恢复后项目重新进入进行中列表，既有配置、计划、资产引用、任务关联和活动记录保持不变。

## 验证

- `corepack pnpm --filter workdsh-plugin-projects test`：通过；覆盖 active/archived 列表隔离、归档后拒绝读取、恢复与持久化事件。
- 本地真实 Preview：取消归档、确认归档、切换已归档筛选、恢复、返回进行中列表均通过。
