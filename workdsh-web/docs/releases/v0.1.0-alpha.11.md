# WorkDSH v0.1.0-alpha.11

本版沿用 DeepSeek Harness `0.1.7-rc.2`，更新 WorkDSH 展示包至 `workdsh-bundle@0.1.0-alpha.50`。专家、连接器、技能、项目、资料库等其余十个运行包沿用 alpha.10 已发行版本。

当 Agent 在会话中使用官方 Playwright MCP 浏览网页时，WorkDSH 在该会话右侧栏显示同一页面。用户可以在侧栏点击、滚动、输入、按键、输入网址、后退与刷新；操作发送给该会话的 Playwright 浏览器，并刷新侧栏画面。页面归属按会话隔离，不把其他会话的浏览器画面混入当前会话。

发行前通过 WorkDSH 全量构建、浏览器 Host 测试、真实 Playwright MCP 集成测试和 Chromium Web UI 回归。该视图使用会话截图与操作桥接；它不是将官方 Browser 插件的独立页面冒充为 Agent 页面。尚需在 Desktop 安装包中验证模型驱动的端到端浏览任务和 Windows/macOS 交互。

## 安装

安装与清单同版本的官方 DSH CLI 和 Node 22.19+，将本 Release 的全部文件放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
```

安装器会校验发行包 SHA-256，并明确安装清单中的 WorkDSH 插件版本。升级前请备份 Profile 配置和数据。
