# WorkDSH v0.1.0-alpha.13

基于 DeepSeek Harness `0.1.7-rc.2`。本版更新 `workdsh-bundle@0.1.0-alpha.52` 和 `workdsh-provider-browser-session@0.1.0-alpha.2`；专家、连接器、技能、项目和资料库继续使用 alpha.12 的版本。

Desktop 启用会话浏览器后，右侧栏只展示“任务浏览器”入口。它与 Agent 的 Playwright MCP 工具操作同一个 Electron 页面；Web 环境继续展示原有浏览器入口。Desktop 安装包无需附带第二份 Chrome、Chromium 或 Headless Shell。

同时需要 Desktop 将各 WorkDSH 模块加入 Profile 的 `dsh.profile.bundles`。仅安装模块依赖并不足以启用专家、项目、资料库和浏览器会话路由；请配合包含此修复的 Desktop 版本使用。

本地已通过构建、类型检查、浏览器会话集成测试。隔离 Profile 中实测了项目和浏览器路由、右侧栏导航、画面点击与 Electron worker 同页状态。Windows 与 macOS 发布安装包仍需在对应 Desktop 流水线验收。

## 安装

将本 Release 的全部文件放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
```

安装器校验每个包的 SHA-256；升级前请备份 Profile 配置和数据。
