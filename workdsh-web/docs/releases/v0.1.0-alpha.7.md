# WorkDSH v0.1.0-alpha.7

这是 WorkDSH 在 Harness `0.1.6-alpha.2` 基线上的维护版。九个可安装包中四个模块更新：skills `alpha.31`、experts `alpha.7`、connectors `alpha.2`、bundle `alpha.47`；identity-local、audit、access、office、activity 沿用当前已验收版本。

## 本版更新

- 修复设置页「外观」切换不生效：工作台客户端不再注册并强制 `workdsh` 深色主题、不再拦截 `theme/change`；外观改由官方 ThemeRuntime 与用户偏好驱动，浅色/深色/跟随系统即时生效，三个选项的选中态恢复显示。
- 能力中心删除「行业应用」标签（用户决定，暂用不到）：专家、技能、连接器三个页面的标签栏只保留专家/技能/连接器；应用域规划与模块登记保留，交付顺序未变。
- 修复设置导航出现两个「Agent 预设」页：移除对官方 `settings.section` 增量槽的包装式注册（保留会话 hero 单座槽接管与守卫）。设置页层面的专家预设过滤随包装移除，官方页自身对不可用预设提供“加载失败”标记与禁用/删除。

## 安装或升级

Release 附带九个 `.tgz`、`SHA256SUMS`、`release-manifest.json`、本说明和校验型安装器。把全部资产放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
dsh --profile workdsh
```

如果 `workdsh` 不存在，安装器创建它；如果已经存在，安装器原地升级插件并保留数据。可用 `--dry-run` 查看命令，也可用 `--dsh /absolute/path/to/dsh` 指定 CLI。安装器不会写入或输出连接器令牌与模型密钥。

## 验证范围

- Node.js `22.23.2`、pnpm `10.34.5`、macOS，Harness `0.1.6-alpha.2`。
- 全仓 build 与 typecheck PASS；集成 110/110、活动 14/14、规划 2/2；`check:plan` PASS（29 模块/50 文档）、`check:versions` PASS（513 条 α2 锁定）。
- 隔离环境全新安装九个包、匿名 401 / 认证 200 边界检查与 Host 冷启动。
- 预览环境浏览器实测：外观三向切换即时生效与选中态恢复、能力中心三标签且无「行业应用」、设置导航单一「Agent 预设」页。
- 九包打包、SHA-256 清单、发布清单和安装器 dry-run。

## 已知边界

- 目前只完成 macOS 验收；Windows 与 Linux 暂缓。
- 卸载、事务式自动回滚、签名、SBOM 和构建来源证明尚未交付。
- 连接器交互式 OAuth、多账号切换和凭据迁移尚未完成；已验证的是令牌授权。
- 小时级专家团稳定性和官方 fork 成员浏览器历史仍未签收。
- 相对 alpha.6，专家团长任务探针、真实模型两阶段交接、连接器隔离探针与腾讯文档实连未在本批制品上复跑。
- 设置页对专家预设的“设为默认/复制”过滤随本版移除，过滤仅保留在会话 hero 席位。
- projects 与 library 源码同步推进到 `0.1.0-alpha.2`，不进入本次安装组合；library 保持独立发行。
- 这是 GitHub 资产发行，未发布 npm；模块 API 与保存数据仍可能变化。
