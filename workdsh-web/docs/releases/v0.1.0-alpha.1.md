# WorkDSH v0.1.0-alpha.1

首个 GitHub 开发预览，交付基于 DeepSeek Harness 官方扩展接口的默认/本地 Skill 管理闭环。

## 已实现

- WorkDSH 品牌和业务导航与 Harness 原生 Sidebar、Workspace、Session、Settings 和 Conversation 组合运行。
- 全局技能目录、搜索、详情、完整 `SKILL.md` 和资源读取。
- 正文与资源编辑、精确 revision 冲突检测、重新发现、打开目录。
- 启用、停用、依赖影响检查、批量操作和可恢复卸载。
- `.zip`、`.md` 与文件夹导入预检、路径和体积限制、完整内容摘要、原子安装及失败恢复。
- `/skill-creator` 通过 Harness 官方 Tool 保存、校验和确认发布草稿；新任务继续使用原生 `/`、`@`、附件、权限、模型与发送能力。
- TSX 领域组件与共享 Modal；未复制 Harness 的 Agent loop、Skill registry、模型路由、Remote transport 或 Conversation renderer。

## 当前范围

当前使用 Harness 默认/本地技能，不提供公共 Skill 市场、SkillHub 或套件。分类没有真实数据时不提供无结果筛选。专家、连接器、项目、资料库等模块仍未完成。

企业版服务端、管理 Web、组织 Skill、版本、分类和下发策略已进入后期 ToDo，不属于本次预览。

## 已知限制

- 锁定 Harness rc.1/rc.2 的外部 workspace Typert 生成仍存在兼容缺口；当前 JSON 管理动作与流式上传使用官方 `dsh-client-connection` 的认证 exact Fetch route。
- 本版本是开发预览，不承诺稳定 API 或数据迁移兼容性。
- 仓库未包含第三方模型凭据，真实模型调用由使用者的 Harness Profile 配置决定。
