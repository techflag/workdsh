# WorkDSH on DeepSeek Harness 0.1.6-alpha.1

发布日期：2026-09-15。源码提交：`bbda262fd0f7d3332d1a9a864d24e0114b2dc811`。渠道：5 个公开 GitHub prerelease；未发布 npm。23 个附件已经无认证下载回读，HTTP 200 且 SHA-256 与本地发行制品一致。

本批将 WorkDSH 的官方运行基线升级到 DeepSeek Harness `0.1.6-alpha.1`，并用官方实验性 Team 服务、工具和 Web 面板替代 WorkDSH 自建的专家团执行器。专家、专家团、角色、技能固定修订和历史记录仍由 WorkDSH 管理；成员创建、任务分配、消息、等待、中断、恢复和运行事实改由官方 Team 与 Session 提供。

## 用户可见变化

- 专家团使用官方 `spawn_teammate` 与共享任务工具；自建 `workdsh_expert_team_*` 工具、SOP 运行状态机和委派 provider 已移除。
- 已发布的旧专家团在下次召唤时生成新的不可变执行修订，删除旧工具指令并加入官方 Team 协作说明；历史会话继续绑定原修订。
- 官方 Team Web 面板显示真实成员和任务活动；WorkDSH 活动插件只负责视觉投影，不维护第二份运行状态。
- 技能、Office 与展示组合改用 0.1.6 的官方 Web/Profile 生命周期；Office 仍是实验性浏览器工作副本能力。

## 验证

在 macOS、Node.js `22.23.2`、pnpm `10.34.5`、DeepSeek Harness `0.1.6-alpha.1` 上完成：

- 全工程 build、typecheck；集成测试 102/102；活动测试 9/9；规划检查 29 模块/50 文档。
- 483 个锁文件中的 DSH 条目均锁定 `0.1.6-alpha.1`，Cordis 仅 `4.0.2`。
- 五模块及三项治理配套 tgz 的隔离 Profile 安装、鉴权、冷启动、移除和重装。
- 官方 Team 生产插件探针覆盖真实成员并发、任务依赖、消息、停止、冷恢复和官方工具调用。
- 浏览器实测确认旧专家团新会话的系统提示词不再含 `workdsh_expert_team_*`，并包含官方 Team 工具。

## Alpha 边界

- 官方 fork Session 的历史查询仍可复现 `seeded session constructor seed must equal its inherited prefix`。成员执行和持久化原始读取可继续，但本批不宣称该官方查询缺陷已经修复。
- P1 长期台账仍有 52 项待验收，其中包含跨平台、60 分钟资源收敛和完整专业质量；它们不是本次升级已经完成的能力。
- 仅完成 macOS Web 验证，未完成 Windows/Linux 端到端验收。
- Office 依赖审计仍有 10 项未收集到随包许可证正文。按项目决定保留现有 notices、依赖名称、声明许可证和来源记录，不宣称许可证文本完整。

详细证据见 [DSH 0.1.6 隔离升级与适配证据](https://github.com/techflag/workdsh/blob/1dd9eadc4f/workdsh-web/docs/evidence/dsh-0.1.6-official-integration.md)。
