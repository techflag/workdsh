# WorkDSH v0.1.0-alpha.8

基线升级到 DeepSeek Harness 0.1.7-alpha.1。整包包含11个 WorkDSH 可安装模块，新增项目与资料库进入整包安装组合。

## 更新

- 项目主页卡片、明暗主题、表单和侧栏分界视觉优化。
- 项目主页与详情路由分离，侧栏项目入口回主页，任务归属入口进入详情。
- 项目输入区共用级联选择菜单，保留原生编辑器、附件与发送；任务能力选择与项目默认配置隔离。
- 适配新 Harness 声明式专家预设；旧修订不静默转换。
- 安装器固定 pnpm 10.34.5 与完整 Harness 传递依赖版本，补齐已检查的原生依赖构建配置。
- 安装器补齐项目/资料库以及官方 base/web-app 升级；Profile 内安装匹配 CLI 与账号 peer，按安装器输出的 Profile CLI 路径启动。

## 安装

安装同版本官方 dsh CLI 和 Node 22.19+，确保 Corepack/pnpm 可用。将全部资产放入同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
```

随后使用安装器打印的 Profile 内 CLI 命令启动。可用 --dry-run 预览命令。安装前自行保留目标 Profile 的可恢复备份。

## 验证和限制

全仓构建、类型检查、集成112项已通过；安装器修复后5项测试通过。浏览器项目主页、菜单、主题、导航和侧栏调宽已实测。11包已完成隔离安装、隔离 Profile 重装和冷启动；已验证273个 DSH 模块版本一致及关键运行时实例一致，浏览器项目主页和资料库打开通过、无页面错误。用户历史 Profile 原地升级仍未验收。

旧目录式专家预设需要重新发布后创建新任务；历史任务不会自动换用新组合。真实模型交付、跨平台、OAuth及多人治理仍有未完成验收项。侧栏 CSS 语义后缀和原生菜单状态适配须随 Harness 升级复验。

发行清单记录源码提交与各安装包 SHA-256。实际对外发布以 GitHub Release 为准。
