# WorkDSH v0.1.0-alpha.5

这是 WorkDSH“专家、技能、连接器”基础版本的安装与升级修正版，运行于 DeepSeek Harness `0.1.6-alpha.1`。九个插件模块沿用 `alpha.4` 已验收版本；本次项目 Release 更新校验型安装器并补齐原地升级验收。

## 本版修正

- 安装器区分新 Profile 与现有 Profile。新装会从官方 Web Profile 初始化；升级只更新插件，不再向已有 Profile 传入 `--from-default-profile`。
- 升级保留 Profile 配置、专家记录、技能、连接器和 Harness 凭据，不覆盖业务数据。
- 安装器在任何 Profile 变更前执行 `dsh --version`，仅接受清单声明的 Harness `0.1.6-alpha.1`，避免不兼容 CLI 造成部分安装。
- 增加安装器集成测试，覆盖全新安装、现有 Profile 升级和不兼容 Harness 的前置拒绝。

## 安装或升级

Release 附带九个 `.tgz`、`SHA256SUMS`、`release-manifest.json`、本说明和校验型安装器。把全部资产放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
dsh --profile workdsh
```

如果 `workdsh` 不存在，安装器创建它；如果已经存在，安装器原地升级插件并保留数据。可用 `--dry-run` 查看命令，也可用 `--dsh /absolute/path/to/dsh` 指定 CLI。安装器不会写入或输出连接器令牌与模型密钥。

## 验证范围

- Node.js `22.23.2`、pnpm `10.34.5`、macOS，Harness `0.1.6-alpha.1`。
- 全仓 build、typecheck、108 项集成测试、14 项活动测试、规划与精确版本检查。
- 隔离环境全新安装九个插件、认证边界检查和 Host 冷启动。
- `alpha.4 → alpha.5` 原地升级，确认三名专家、自定义技能、连接器、凭据状态、Profile 配置标记和业务记录哈希保持不变，升级后 Host 冷启动成功。
- 九包打包、SHA-256 清单、发布清单和安装器 dry-run。

## 已知边界

- 目前只完成 macOS 验收；Windows 与 Linux 暂缓。
- 卸载、事务式自动回滚、签名、SBOM 和构建来源证明尚未交付。
- 连接器交互式 OAuth、多账号切换和凭据迁移尚未完成；已验证的是令牌授权。
- 小时级专家团稳定性和官方 fork 成员浏览器历史仍未签收。
- 这是 GitHub 资产发行，未发布 npm；模块 API 与保存数据仍可能变化。
