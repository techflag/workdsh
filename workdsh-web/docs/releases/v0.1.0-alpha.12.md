# WorkDSH v0.1.0-alpha.12

本版基于 DeepSeek Harness `0.1.7-rc.2`，新增 `workdsh-provider-browser-session@0.1.0-alpha.1`，更新组合包至 `workdsh-bundle@0.1.0-alpha.51`。专家、连接器、技能、项目和资料库沿用 alpha.11 的已发布版本。

Desktop 浏览器任务复用应用已有的 Electron Chromium。每个 Agent 会话拥有独立的浏览器 worker；官方 Playwright MCP 工具和右侧栏操作连接该会话的同一页面。旧的系统浏览器启动方式仅保留给 Web 环境。发行包不额外附带 Chrome、Chromium 或 Headless Shell。

本地已通过构建、类型检查、双会话浏览器工具与画面/点击集成测试，以及两个 Desktop 变体的一致性和类型检查。Windows 与 macOS 安装包中的实际任务、权限和会话恢复仍需在 GitHub Actions 产物上验收。

## 安装

将本 Release 的全部文件放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
```

安装器校验每个包的 SHA-256；升级前请备份 Profile 配置和数据。
