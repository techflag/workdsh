# WorkDSH v0.1.0-alpha.9

本次 Alpha 更新资料库界面：新建菜单、文件操作菜单和最近资料列表与现有控件风格保持一致，并修正菜单靠近窗口边缘时的位置。

预览 Profile 启动及安装时会移除与 WorkDSH 专家插件重复装配的独立 Agent Team Profile，避免重复的 Team loader。官方 Team 执行仍由专家插件装配。

## 验证和限制

Node 22 下完整构建和类型检查通过；资料库插件测试 5 项、预览去重测试 2 项通过。隔离 Profile 的团队 Web 探针 15 项和真实模型探针 16 项通过。本机预览已安装并重启，18989 服务返回预期登录状态。尚未完成用户历史 Profile 原地升级、Windows 与 macOS Desktop 安装包验收。制品版本和 SHA-256 以发行清单为准。

## 安装

安装与清单同版本的官方 DSH CLI 和 Node 22.19+，将全部发行文件放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
```

这是 Alpha 预发布；安装前备份目标 Profile 的配置和数据。
