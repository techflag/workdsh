# WorkDSH v0.1.0-alpha.6

这是 WorkDSH 升级到 DeepSeek Harness `0.1.6-alpha.2` 的项目发行版。九个可安装包中五个模块更新：skills `alpha.30`、experts `alpha.5`、office `alpha.7`、activity `alpha.4`、bundle `alpha.46`；identity-local、audit、access、connectors 沿用当前已验收版本。

## 本版更新

- 全部官方依赖精确锁定升级到 `0.1.6-alpha.2`；六个客户端插件完成 Client Session 迁移：当前会话按官方 `SessionSummary.retainedBy.mainView` 推导，打开会话使用官方 `uiWorkspace.openSession` 导航。
- 专家成员与子代理根会话改用官方 `sessions.subagentAddress` 解析；活动成员观测改用官方 `retain`/`ready`/`release` 世代语义，未 retain 的成员会话不强行绑定。
- Office 新增 CSV 只读表格预览：单元格网格线、冻结表头与行号列、分隔符识别与编码回退；word-only 精简制品不再注册 CSV 预览，与 `release-scope.json` 的 `docx` 声明一致。
- 组合包外部 URL 契约变化：`?workdsh-view=assistant|automation|more` 不再切换视图，静默回落到对话视图且不报错。
- 安装器集成测试断言同步到 Harness `0.1.6-alpha.2`，避免升级批次出现假通过。

## 安装或升级

Release 附带九个 `.tgz`、`SHA256SUMS`、`release-manifest.json`、本说明和校验型安装器。把全部资产放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
dsh --profile workdsh
```

如果 `workdsh` 不存在，安装器创建它；如果已经存在，安装器原地升级插件并保留数据。可用 `--dry-run` 查看命令，也可用 `--dsh /absolute/path/to/dsh` 指定 CLI。安装器不会写入或输出连接器令牌与模型密钥。

## 验证范围

- Node.js `22.23.2`、pnpm `10.34.5`、macOS，Harness `0.1.6-alpha.2`。
- 全仓 build、typecheck、110 项集成测试、14 项活动测试、2 项规划测试与精确版本检查。
- 隔离环境全新安装九个插件、匿名 401 / 认证 200 边界检查和 Host 冷启动。
- 九包打包、SHA-256 清单、发布清单和安装器 dry-run。

## 已知边界

- 目前只完成 macOS 验收；Windows 与 Linux 暂缓。
- 卸载、事务式自动回滚、签名、SBOM 和构建来源证明尚未交付。
- 连接器交互式 OAuth、多账号切换和凭据迁移尚未完成；已验证的是令牌授权。
- 小时级专家团稳定性和官方 fork 成员浏览器历史仍未签收。
- projects 与 library 源码同步推进到 `0.1.0-alpha.2`，不进入本次安装组合；library 保持独立发行。
- 这是 GitHub 资产发行，未发布 npm；模块 API 与保存数据仍可能变化。
