# WorkDSH v0.1.0-alpha.3

这是 WorkDSH 的第一个“专家、技能、连接器”基础版本，运行于 DeepSeek Harness `0.1.6-alpha.1`。它把三类核心能力作为一套可安装的项目发行交付，同时附带本地身份、审计、授权、协作动态、Office 工作副本和 WorkDSH 展示组合。

## 基础能力

- **专家**：创建与发布专家定义，绑定已审技能修订；执行时组合 Harness 官方 Agent Team Host、九项团队工具和官方 Client 面板。WorkDSH 活动条显示专家真实姓名、当前任务和交接状态，并在队友完成后回到仍在工作的主理人。
- **技能**：发现、搜索、创建、导入、编辑、启停、恢复和卸载本地技能，保留 `SKILL.md` 与资源文件，并通过 Harness 原生任务调用。
- **连接器**：管理多个独立 MCP 实例，支持 stdio 与 Streamable HTTP；凭据进入 Harness 官方凭据服务，工具与资源由官方 MCP Client 发现。新会话默认不选择连接器，用户显式选择后只把该实例的工具命名空间用于本次对话。

## 本版修正

- 专家团活动状态以官方共享任务为准，已完成队友不再长期占用顶部状态；lead 和成员显示专家作品中的真实姓名。
- Office 工具兼容模型偶发的一层 JSON 字符串包装，同时保留对象、文档类型、操作上限、权限和修订冲突校验。
- DOCX 分析图表使用可编辑的原生图表结构与嵌入工作簿，不再把图表作为 PNG/Base64 图片插入。
- PPT 原生编辑画布使用权威 1280×720 CSS pixel 坐标，修正按 960×540 point 写入后内容集中在左上角的问题。

## 安装

Release 附带九个 `.tgz`、`SHA256SUMS`、`release-manifest.json`、本说明和校验型安装器。把所有资产放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
dsh --profile workdsh
```

安装器先校验每个包的 SHA-256，再按身份、审计、授权、技能、专家、连接器、活动、Office、展示组合的顺序调用官方 `dsh plugin add`。可先用 `--dry-run` 查看命令。它不会写入连接器令牌或模型密钥。

## 后续需要完善

### 发布前高优先级

1. **专家团长任务稳定性**：生产安装组合的长任务、人工停止后继续、任务与消息交接、浏览器重连、成员失败提示及 Host 冷重启恢复已由可控故障验收覆盖；真实模型的有界两阶段交接也已通过。小时级专业任务和官方 fork 浏览器历史仍需单独验收。
2. **连接器账号授权**：实现交互式 OAuth、刷新与撤销、多账号切换、过期提示和凭据迁移；当前真实验证是令牌授权。
3. **安装与升级**：加入卸载、升级、回滚和失败恢复，并在 Windows、Linux、macOS 上做冷启动验收。当前发行是 GitHub `.tgz` 资产，不是签名桌面安装包或 npm 包。
4. **供应链证据**：在 SHA-256 基础上补签名、SBOM、构建来源证明和依赖许可证缺口处置。

### Beta 前产品完善

1. **专家与技能生命周期**：版本迁移、依赖解析、冲突提示、跨机器导入导出和团队模板。
2. **连接器生态**：可搜索目录、标准授权适配器、连接诊断、限权说明和服务端能力分组。
3. **Office 保真**：复杂 PPT/DOCX/XLSX 模板、外部原生图表反向导入、字体替换、撤销恢复以及 Word/WPS/PowerPoint 交叉验收。
4. **部署边界**：公网多用户的身份、租户隔离、RBAC、审计留存和管理员能力。当前版本面向可信本地用户。
5. **质量与体验**：大目录和长会话性能、无障碍、国际化、崩溃诊断、更新提示和完整上手文档。

## Alpha 边界

模块 API 与保存数据仍可能变化。Office 和协作动态随项目包提供，但不扩大本次“专家、技能、连接器基础可用”的核心承诺。小时级专家团任务、任意 Office 模板保真、多平台与公网多租户仍未完成最终验收。
