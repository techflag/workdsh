# WorkDSH v0.1.0-alpha.2

项目级 alpha 预览，基于 DeepSeek Harness `0.1.6-alpha.1`。这是继早期 Skill 单模块预览之后，首次把当前 WorkDSH 模块作为一套项目发行交付。

## 主要能力

- WorkBuddy 式开源工作台：任务、执行过程、人工介入和可编辑成果保持在同一会话。
- 技能管理、技能创建与 WorkBuddy 技能包兼容。
- 专家定义与已审修订，执行层使用 Harness 官方 Team 能力。
- Office 工作副本，支持当前范围内的 PPTX、XLSX、DOCX、PDF、HTML 预览、编辑和导出。
- 官方 Browser Use、Computer Use、Web 终端、归档会话、MCP 资源与 URI 模板等 Harness `0.1.6` 能力。
- 多实例 MCP 连接器管理：stdio 与 Streamable HTTP、官方凭据存储、工具/资源发现、启停与按会话工具隔离。

## 真实连接器验证

腾讯文档使用官方 Streamable HTTP 地址与 `Authorization` 令牌接入。令牌写入 DSH 官方凭据服务，不出现在连接器列表、诊断与发布文件中。实测发现 224 个工具，并在 WorkDSH 会话内完成账号文档只读查询。

新会话默认不选择任何连接器。选择成功后详情弹窗关闭，连接器名称显示在输入框旁；当前会话只获得所选连接器的 MCP 工具命名空间。

## 安装资产

Release 附带当前组合所需的九个预构建 `.tgz`、`SHA256SUMS` 与 `release-manifest.json`。使用官方 Harness CLI，在目标 Profile 停止后安装所需模块。npm 注册表尚未发布。

当前 Release 不提供一键安装器。必须安装 `workdsh-plugin-experts-0.1.0-alpha.3.tgz` 才会出现官方 **Agent Team**；只安装 Skill 与展示包不会加载专家和 Team Client。建议按身份、审计、授权、技能、专家、连接器、活动、Office、展示包的顺序逐项执行官方 `dsh plugin add`。

官方 Agent Team 面板与 WorkDSH 活动插件各司其职：面板展示成员和共享任务，Siri 风格活动条展示本轮状态；团队正在处理时显示彩色环绕动画，完成后转为静态结果状态。

## 验证

- Node.js `22.23.2`、pnpm `10.34.5`、macOS。
- 全仓 build、typecheck、集成测试、规划与版本检查。
- 连接器打包、官方 MCP Client 工具/资源发现、启停恢复、多实例增删、默认空选择、选择持久化与会话工具隔离。
- 真实 WorkDSH 页面验证新会话默认空选择，以及详情选择后弹窗自动关闭。

## Alpha 边界

- 腾讯文档当前验证的是令牌授权；交互式 OAuth 尚未实现。
- 完整专家团队长任务、复杂 Office 模板保真、多平台和公网多租户部署仍未完成最终验收。
- 各模块保留独立版本线，项目 tag 不改变各插件包内版本。
