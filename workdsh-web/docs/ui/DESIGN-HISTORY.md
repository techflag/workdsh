# WorkDSH UI 提案 v3

状态：待用户审阅。2026-09-10。依据用户提供的 WorkBuddy 截图与既有项目设计；v1 的独立视觉风格被用户指出与参考差距过大，v2 按 WorkBuddy 布局与中性灰黑视觉重新对齐，仍待审阅。

## 范围与开发顺序

用户要求在正式工作台实现前先审阅完整产品方向。本次是设计交付，放在 docs/ui，不增加可加载插件、不改变 D01 状态。D01 公开接口门槛完成后，D02 开始承接工作台；后续模块按既定 D03—D15 逐项接入。探针界面不作为最终视觉基线。

## 视觉规范

- 以用户 WorkBuddy 截图为布局参考，不再采用 v1 的绿色品牌强调、大标题项目页和事件时间线。
- 中性背景 #121212，侧栏/配置栏 #202020，边线 #343434，正文 #e7e7e7，次要文字 #909090。主要按钮浅灰，选中导航深灰；彩色仅用于能力图标和助手标识。
- 桌面三栏：左导航约 17.55vw，项目配置约 20.4vw，中间自适应；1440px 下约 253 / 893 / 294px。顶栏 57px。项目动态独立滚动，底部输入区保持可见。
- 项目页：面包屑与邀请在顶栏；四标签紧贴顶部；发布留言、相关动态筛选、助手欢迎正文、底部输入、右侧五组配置。
- 首页采用居中标题、场景分组和宽输入区；取消英文标语、序号装饰与绿色卡片。其他页面同步中性主题。
- WorkDSH 品牌仍保留。专家暂用字形头像，未复制第三方人物素材；助手/更多等尚未细化的导航和表单仍有差异，不宣称像素级复刻。
- 保留可见键盘焦点、输入标签、Escape 关闭弹窗；小屏变为纵向布局，作为原型适配，非移动产品最终方案。

## 页面与交互

| 页面 | 信息与操作 | 正式实现归属 |
| --- | --- | --- |
| 首页 | 工作空间、任务输入、专家/资料选择、场景快捷填入 | workbench；能力来自各插件 |
| 任务 | 对话、真实执行进度、拟提交内容审阅、右侧成果预览与引用 | Harness Conversation/Slots；领域服务提供业务操作 |
| 能力中心 | 专家/技能/连接器/行业应用标签、搜索、对象卡片、创建入口 | experts / skills / connectors / applications |
| 项目 | 动态/计划/任务/资产、项目指令、专家/技能/连接器关联、成员入口 | projects；内容仍由 library 拥有 |
| 资料库 | 最近资料、所属空间、导入与成果引用 | library |
| 自动化 | 明确规划中，不能创建假调度 | automations，P2 |
| 组织管理 | 独立入口，后续成员/策略/审计，权限不足不可进入 | admin + identity/access/audit |

原型可操作：导航、能力标签、名称/描述搜索、项目标签、示例/空状态切换、场景填入、任务布局入口、示例文件预览和说明弹窗。创建专家/技能、邀请、保存配置等表单尚未细化，不应将说明弹窗作为最终交互验收。

## 首期空状态与异常规范

没有任务时说明如何发起；没有对象时提供创建/导入；搜索无结果时保留关键词并提示修改。正式未实现功能显示“规划中”，不使用已完成数据填充空页面。

正式 Remote 接入还须实现加载、重试、断线、无权限、授权失效、修订冲突和部分成功状态。只有服务回执确认后才能显示“已提交”；未知结果先核对，不盲目重试。组织管理员不默认获得个人内容。

## 技术约束

原型自身的 HTML 页面切换仅用于设计审阅，不移植为自有运行时。正式页面通过 Harness 公开 Client / Slots / Remote 能力实现；不另建 React 根、Agent loop、传输层或会话状态镜像。品牌与布局扩展是否支持所需细节，须按 rc.1 公开接口验证，发现限制记录差异。

各插件贡献视图，工作台只组织入口；不得由一个大 UI 文件直接访问全部领域内部实现。管理入口与用户入口共用授权后的领域服务，没有第二套数据库。

本轮验证原型页面和交互，不计为 P1 产品验收。用户审阅视觉方向后，补充创建/编辑表单和异常态细节；真实产品实现仍按 D01 门槛推进。

## 图标与可读性修订 v3

按用户反馈替换字符拼接导航为本地 SVG：24×24 坐标，常规 1.7px 圆角描边，导航显示 22px，工具栏 18—21px；采用同一套轮廓规则，不依赖图标字体/CDN。实现位于 ui/icons.js。

侧栏图标与文字垂直对齐，固定图标槽位；加号、语音、速度、发送、搜索、筛选、面板切换统一 SVG。专家头像为简洁人物轮廓，技能字章保留为业务类型标识；正文中的表情仅作为示例内容。

正文 15px/1.8 行高、次要文字提高至 #a5a5a5 附近；输入占位提高对比度；不对截图施加缩放或锐化模拟清晰度。细节仍待用户实际显示环境审阅。
