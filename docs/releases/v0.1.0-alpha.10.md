# WorkDSH v0.1.0-alpha.10

本次发布将 WorkDSH 的 11 个运行包按官方 DeepSeek Harness `0.1.7-rc.2` 重新构建和打包。专家与官方 Team、连接器、技能、项目、资料库、Office、活动及本地治理插件均使用当前源码与精确锁定的 rc.2 公开接口；安装清单记录每个包的版本、SHA-256 和源码提交。

Web 预览的设置页已显示 `0.1.7-rc.2`，并通过独立空 Profile 的源码预览安装及本次发行包安装器的 dry-run 检查。构建、类型检查及各模块测试的实际结果见 [升级记录](../DSH-0.1.7-UPGRADE-PLAN.md)。

## 安装

安装与清单同版本的官方 DSH CLI 和 Node 22.19+，将全部发行文件放在同一目录，停止目标 Profile 后执行：

```sh
node install-workdsh.mjs --profile workdsh
```

安装器校验发行包的 SHA-256，并明确授权其记录的 WorkDSH 插件版本。首次安装前请备份现有 Profile 的配置和数据。

## 已知限制

这是 Alpha 预发布。Agent 的 Playwright 浏览器与右侧栏 Browser 仍是独立页面；普通链接在侧栏打开不代表 Agent 的导航和点击已在同一页面可见。Windows/macOS Desktop 安装包和实机运行需单独验收；本 Web 发布不代表这些工作完成。
