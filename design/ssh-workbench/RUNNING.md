# 真实 SSH 工作区

本次新增的正式代码位于 Desktop 包内，与本目录的静态演示原型分开。

## 使用

满足根仓库 Node/Yarn 版本并安装依赖后，在根目录运行：

```sh
corepack yarn dev:beta
```

在 Desktop 设置中选择增强或扩展模式，重启后点击右下角“SSH 工作区”。兼容模式保持官方页面。

1. 点击“连接”，输入主机、端口、用户名和密码，或粘贴私钥与口令。
2. 点击“核对指纹”，与服务器管理员提供的指纹比对。
3. 确认后连接。顶部标签可切换主机，终端输入直接发送给远程 Shell。
4. 左侧显示远程用户目录。进入文件夹，或输入远程绝对路径。
5. 点击“上传”选择文件。右侧显示真实传输进度，可取消；同名文件会拒绝上传。
6. 点击文件下载，当前上限 32 MB。
7. “返回 AI”切回 Harness 页面，SSH iframe 保留；关闭主机标签或 Desktop 会断开连接。

## 当前边界

- 已实现 SSH 密码/私钥认证、指纹核对、远程交互终端、多会话、SFTP 目录、上传下载。
- 主机信息与指纹保存在当前浏览器存储；密码、私钥和私钥口令不持久化。
- AI 当前仍是 Harness 原有界面，尚未接入 SSH 输出与工具；也未迁移静态原型的全部文件编辑、队列策略与设置。
- 本地终端、SSH agent/ssh_config、跳板机、自动重连、覆盖写入、断点续传、远程文件编辑尚未实现。
- SSH 路由仅允许回环地址，不通过 LAN 浏览模式对外开放。
- 不是已发布版本；需要完成原型功能迁移与发布验证后才能作为完整 SSH 产品发行。
